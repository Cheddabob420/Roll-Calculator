    How to Use Run Length

    1. Enter Total Run Length: Input the total footage of your run.
    2. Subtract Roll Footages: Enter the footage of each roll used and click "Add Roll" (or press Enter).
    3. Monitor Remaining Footage: Displays remaining footage. Turns red when below 5,000 ft.
    4. View Results: Shows final butt roll footage when complete.
