Each entry after initial run length is added here and subtracted from remaining footage.

    How to Use

    1. Enter Total Run Length: Input the total footage of your run.
    2. Subtract Roll Footages: Each time you click "Next", enter the footage of the roll you're using and the system will subtract it.
    3. Monitor Remaining Footage: The display shows your remaining footage. It turns red when below 5000 ft so you know you will have enough time to get the next up.
    4. View Results: When you go negative, you'll see the final butt roll footage and whether it's suitable to return to storage.

    Color Indicators

    • Green - Butt roll is 5000 ft or more (good to return)
    • Red - Butt roll is under 5000 ft (too small, consider splitting another roll)
