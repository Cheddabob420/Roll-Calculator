Run Length Calculator

Enter your total run length, then subtract individual roll footages to calculate the remaining butt roll.

How to Use Run Length

  1. Enter Total Run Length: Input the total footage of your run.
  2. Subtract Roll Footages: Each time you click "Next", enter the footage of the roll you're using.
  3. Monitor Remaining Footage: Displays remaining footage. Turns red below 5,000 ft.
  4. View Results: Shows final butt roll footage when negative.

How to Use Takeup Calculator

  1. Enter Flat Lineal: Input your target paper/liner lineal footage.
